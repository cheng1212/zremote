# zremote UI 设计规格书（Citrus Morning / 柑橘晨光）

> 用途：供任何 App/框架 1:1 复刻此 UI 风格。所有数值均为代码实测值，非估算。
> 风格一句话：**新粗野主义（Neo-Brutalism）浅色主题**——奶油底 + 墨线描边 + 硬阴影（无模糊）+
> 蜜橘主色；状态色语义固定；一切可点区域 ≥48dp；按压有"沉入阴影"的物理反馈。

---

## 一、设计语言总纲

1. **无渐变、无模糊阴影**：所有阴影 blurRadius=0（硬阴影），位移即阴影形状。
2. **一切有描边**：卡片/按钮/chip/输入框全部带墨色描边（宽度按层级 1.1~2.2）。
3. **按压=沉入**：可按压元素按下时向右下位移 2.5px 且阴影消失（"按进纸面"），
   松手 90ms 弹回。
4. **圆点会呼吸**：运行中状态圆点 900ms 反复渐隐渐显（0.35→1.0）。
5. **单主题**：仅浅色（奶油底），无深色模式。
6. **触控底线**：任何可点区域 ≥48×48dp（视觉可小，热区不可小）。

## 二、色彩系统（精确值）

| 令牌 | 色值 | 用途 |
|---|---|---|
| `bg` | `#FFF6E9` | 页面背景（奶油） |
| `surface` | `#FFFCF5` | 卡片/输入框底 |
| `ink` | `#241C15` | 主墨色（文字/描边/阴影/深底气泡） |
| `inkSoft` | `#5C5044` | 次级文字 |
| `inkFaint` | `#7A6853` | 微标签灰棕（对比度 ~4.6:1，10px 小字可读） |
| `line` | `#E8DCC8` | 分隔线/禁用底 |
| `primary` | `#FF6B1A` | 蜜橘主色（主按钮/选中/running） |
| `primaryDeep` | `#E05500` | 深橘（强调文字/聚焦边框） |
| `aqua` | `#0FB5A3` | 青=完成/成功/继续/子代理 |
| `lemon` | `#FFC93C` | 柠黄=排队/暂停/预热/警示 |
| `rose` | `#E5484D` | 玫红=错误/删除/停止/危险 |
| `grape` | `#7C5CFF` | 葡萄紫=思考等级/技能/等待输入 |
| `onInk` | `#FFF6E9` | 深底上的文字（与 bg 同色） |

**状态色语义（固定，勿混用）**：running=橘 / done=青 / error=玫红 / queued=柠黄 /
thinking·等待输入=葡萄紫。

**对比度纪律**：10px 级微标签用 `inkFaint`（加深到 ~4.6:1），禁用更浅灰。

## 三、形状与阴影系统

- **全局圆角** `radius = 14`（卡片/按钮/输入框）；小元素 8~12；chip 用 StadiumBorder（全圆）。
- **描边宽度语境**：普通卡片 1.6 ｜ 子卡/次要 1.2~1.3 ｜ 主按钮/气泡 1.8 ｜ 聚焦输入框 2.2（深橘）。
- **硬阴影** `hard(dx=3, dy=3, blur=0, color=ink)`；主按钮/气泡用 dx=2.5；
  按下时阴影清空 + 位移 (2.5, 2.5)。
- **弹层**：顶部圆角 20，SafeArea 包裹， grabbed handle：44×4 圆角条（color: line）居中。

## 四、触控与动效数值

| 项 | 值 |
|---|---|
| 最小触控目标 | **48×48dp**（全局 IconButton 主题强制：minSize 48 + padding 12 + padded） |
| 按压沉入位移 | 2.5px（右下 45°），AnimatedContainer 90ms |
| 折叠展开 | AnimatedSize 150ms easeOut |
| 行入场 | FadeTransition + SlideTransition(0→4% 高度)，180ms easeOutCubic，按 rowId 只播一次 |
| 状态圆点呼吸 | 900ms repeat(reverse)，透明度 0.35~1.0 |
| 流式重排节流 | 200ms（文本没变不重排） |
| 锚定微动画 | 60~110ms linear，单步 ≤600px，<1.5px 不动 |

## 五、文字规格

| 元素 | 字号/字重 |
|---|---|
| AppBar 标题 | 18 / w800 / letterSpacing -0.2 |
| 弹层大标题 | 16 / w900 |
| 卡片标题 | 14.5 / w800 |
| 正文/气泡 | 14 / h1.45~1.5 |
| 次级说明 | 12.5~13 / w600（inkSoft） |
| 微标签/chip | 10.5~12.5 / w700~w800 |
| 阶段行（气泡内） | 10 / onInk |
| 错误详情 | 9~11 / rose 系 |
| 代码/模型名/路径 | fontFamily: monospace |
| 品牌大字（配对页） | 40 / w900 / letterSpacing -1.5 |

规则：正文中文用系统默认字；**代码、模型 id、文件路径一律 monospace**。

## 六、核心组件规格

### 6.1 BigButton（主按钮）
- 蜜橘底 `primary` + 墨描边 1.8 + 硬阴影 2.5；文字白 14.5/w800/ls 0.2；图标 17。
- 内边距 h18/v11；`expand=true` 时占满行宽居中。
- 禁用态：底 `line`、字 `inkFaint`、无阴影。
- 按下：位移 (2.5,2.5) + 阴影消失（90ms）。
- 无障碍：包 Semantics(button: true)；HitTestBehavior.opaque。

### 6.2 HardCard（硬阴影卡片）
- `surface` 底 + 墨描边 1.6 + 硬阴影 dx3；radius 14；padding 12（常用 14/10~16）。
- 可点版本：**Material(transparent) → Ink(装饰) → InkWell**（涟漪盖在装饰上，
  不藏进不透明背景——这是关键写法）。

### 6.3 StatusChip（状态徽章）
- StadiumBorder + 状态色描边 1.2 + surface 底；圆点（6/7px，运行态呼吸）+ 文字
  （compact 10.5 / 常规 11.5，w700，height 1）。
- phase→颜色全表：running=橘"运行中" / prewarming=柠"预热中" / queued=柠"排队中" /
  waitingInput=紫"等待输入" / idle=灰棕"空闲" / completed·completedSuccess=青"已完成" /
  error·completedError=玫红"出错" / paused=柠"已暂停" / 未知=原样显示。

### 6.4 发送/停止二态按钮（圆形 48dp）
- 停止态：`rose` 底 + 白停止图标 26 + 墨描边 1.8 + 按下沉。
- 发送态：有字=`primary` 底白上箭头 24；busy=灰底转圈（13px 内边距 stroke2.4）。
- 无字无附件 → 停止；有字/有附件 → 发送。停止点击带 mediumImpact 震动。

### 6.5 暂停/继续按钮（圆形 42dp）
- 墨描边 1.8 + 硬阴影；跑动=柠檬底暂停图标（24），已暂停=青底继续。
- 位于发送键左侧，间距 6。

### 6.6 气泡（用户消息，微信式）
- 图片：**独立于气泡外**，右对齐一块一张，12px 圆角、无边无底、原始比例
  （宽=屏宽 82%，高≤420 封顶按比例收窄；DPR cacheWidth）。
- 文字/文件：进墨色气泡（`ink` 0.72~1 底、onInk 字 14/h1.45），最大宽 82%，
  圆角不对称（topLeft 14 / topRight 4 / 其余 14），描边 1.6。
- 附件分两类渲染：图片走独立块；非图片=气泡内 chip（文件图标 aqua + 名·大小）。

### 6.7 回显气泡（发送中）
- 同用户气泡形，底 `ink` 0.72；failed=玫红 0.14 底+玫红字。
- 状态行（9~10px）：转圈(9px stroke1.6) + 阶段文案（"读取/上传 xx%"/排队中）；
  20s 亮「响应较慢」斜体；上传阶段亮玫红「取消」。
- 失败：friendlyError（10.5 w800 rose，最多2行）+ 原始错误（9px 0.7 透明度）
  + 按钮「重试」「切 GLM 重试」。

### 6.8 代码块（Markdown pre）
- 外层：codeblockDecoration=`ink` 底、圆角 10、描边 1.4、内边距 10。
- 头部：语言名（10.5 w800 ls0.8，onInk 55%）+ 复制钮（15px 图标，点击变 check
  1600ms 后复原），头部与正文之间 white12 分隔线。
- 正文：12px monospace h1.55 onInk，**完整铺开软换行、无内滚、无高度封顶**
  （超 10 万字符截断+提示行）。
- 行内 code：12.5 mono、`bg` 底、`primaryDeep` 字。

### 6.9 工具卡 / 子代理卡（时间线）
- 工具卡：surface 底+描边 1.3（色=状态：streaming 橘 / failed 玫红 / 完成 青）、
  右边距 20、点击展开；头部=状态图标(11~13px)+名称(mono 12.5 w800)+折叠箭头；
  展开后「输入/输出」mono 段（ConstrainedBox maxHeight 240 内滚）。
- 子代理卡：aqua 0.09 底+青描边；PulseDot(animate=streaming)；展开正文走
  MemoMarkdown(12.5)。

### 6.10 计划面板
- surface 卡+描边 1.6+硬阴影 3；头部=树图标+"执行计划 · N/M"+进度条
  （aqua，minHeight 5，bg line）；折叠时显示「▶ 当前步骤」单行。
- 步骤行：18px 图标位（完成=青 checkbox / 进行中=橘 indeterminate / 待办=空心灰）+
  内容 12.5（完成灰+删除线，进行中 w700 橘字）。

### 6.11 询问交互面板（AskUserQuestion）
- 每题一块：题干 12.5 w800 + 选项药丸 Wrap；选中=深底白字反色；
  多选=toggle；「其他…」展开自由文本输入（顶层 payload.freeText 控制）。
- 提交钮：`!busy && allAnswered` 才可用；载荷
  `{action:'accept', content:{answers:[{question, selected:[…]}]}}`（桌面 zod 实测）。

### 6.12 排队条（会话跑动时的追加队列）
- 柠檬 0.25 底+顶部描边；头行=队列图标+「排队中 N 条」+追问入口（stadium 34px 高）
  +「自动消化」Switch。
- 每条：单行省略文本 + 上移(非首条)/编辑/立即发送/删除 四个 19px 图标钮。

### 6.13 空态/三态
- 空会话：挥手图标 30 + 「发第一条消息，开始这个会话」（13 inkSoft，top 48 居中）。
- 加载：16~22px 转圈（primary 或 onInk）+ 可选 13px 说明（"正在同步会话…"）。
- 错误：玫红系文案（人话映射）+ 重试按钮；订阅失败=大字+BigButton 重试。
- 断线：顶部横幅（降级原因+就地重连），列表变只读快照。

## 八、交互模式（全 App 统一）

1. **长按=操作菜单**：消息行/任务卡长按弹底部操作表（每行 48dp 级、pop 后执行）。
2. **弹层三件套**：grab handle + 标题(16 w900) + 内容；`showModalBottomSheet`
   + `isScrollControlled` + SafeArea；高度 0.5~0.7 屏封顶；点外部=取消。
3. **点选即生效**：选项类弹层点选后 pop 并立即应用（乐观 UI），失败回滚+红条。
4. **危险操作**：AlertDialog 确认（surface 底+描边 1.6+取消 TextButton+BigButton）；
   删除类文案必须含"不可恢复"。
5. **触觉**：发送=selectionClick；停止/长按=mediumImpact。
6. **错误文案**：一律人话+下一步动作（"点击重试"/"先去桌面端打开它"），
   原始异常可小字附注；禁整段糊原始 stack。
7. **乐观 UI 三段**：先改本地 → 发 RPC → 失败回滚+红条；成功后由服务端快照权威化。

## 九、禁则（做了就破功）

1. 禁渐变、禁 blurRadius>0 的柔阴影、禁彩色大色块铺底。
2. 禁 48dp 以下触控热区（视觉小可以）。
3. 禁无描边的可点元素（透明底也必须有 InkWell 边界反馈）。
4. 禁把涟漪藏在 Container 不透明背景里（必须 Material+Ink 写法）。
5. 状态色禁止串用（rose 只表危险系，aqua 只表完成/成功系）。
6. 禁整段原始异常糊给用户（必须人话映射，原始值最多 9px 小字附注）。
