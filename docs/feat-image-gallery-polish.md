# 变更说明：图片消息观感与预览体验打磨（对齐参考截图）

> 基线：`32a1237`（图片上传与预览增强）
> 日期：2026-09-09　依据：用户实测反馈三点 + 参考截图（相册卡编排）

## 用户反馈 → 对应改动

### 1.「编排参考截图，原底色太丑」

- 多图改**紧贴马赛克网格**（参考截图的相册卡）：
  - 2 图并排（格子高 0.95 宽）
  - 3 图「左大右两小」经典排法
  - ≥4 图两列分行
- 格子缝 3px、圆角 8、**无描边无底色**——去掉原先每格的白/14% 填充+
  白边（用户说的丑底色）；加载占位是素色圆角块，成图后不跳
- 分区照旧：图片网格在前，非图文件 chip 纵排在后

### 2.「进聊天记录后可左右滑动预览」

- 新增 `openImageGallery`：PageView 全屏画廊，**左右滑动逐张看**，
  底部 `n / N` 计数，右上关闭，点图/背景退出
- 点任意网格格子进画廊，定位到点的那张；单图仍走原全屏查看器（可双指缩放）
- 画廊字节收集：本地直显 > 全局缓存 > attachmentRead，个别失败跳过不阻塞

### 3.「选照片阶段只显示缩略图，不要名字；上传阶段也要能预览」

- 输入栏附件条：图片改为**纯 52px 缩略图**（点按全屏预览，右上角小 ✕ 移除），
  不再带文件名/大小；非图文件维持名称 chip
- 发送中回显气泡：**与正式气泡同一套网格编排**——本地字节直显
  （`_prefetchUploads` 把读好的字节连同嗅探出的 mime 写进 echo 附件，
  上传完成前就能看图，不再是干等文案）；早期失败退回 64px 本地缩略图，
  该路径也补了魔数兜底（无后缀图不再退化成灰色图标）

## 验证

- `flutter analyze` 0 问题；`flutter test` 112 过 / 13 skip；`dart format` 全量
- 上传协议未动（仍 attachmentBegin/Chunk/Commit），全部改动在展示层与本地预览

## 审核提示

- echo 附件在读取阶段逐个追加（每读一个刷新一次列表）→ 上传前缩略图
  逐张出现，而不是最后一次性弹出
- 画廊里 InteractiveViewer 双指缩放未带（与横向翻页手势冲突），
  单图查看器保留缩放；用户主要诉求是滑动翻看
