# 变更说明：图片消息改「一张一张」+ 去黑边 + 选图条可滑

> 基线：`5808358`（图片观感与预览打磨）
> 日期：2026-09-09　依据：用户对 v4 的反馈（参考图二：圆角/浅底/去黑边）

## 反馈 → 改动

### 1. 选图条要能左右滑动
- 附件条缩略图列表加 `AlwaysScrollableScrollPhysics` + Bouncing：
  图多时横向滑动翻看，图不满一屏拖动也有滚动反馈（之前图正好
  占满时看不出能滑）。

### 2. 去黑边（参考图二的软边风格）
- 选图条外框：黑描边 → `ZT.line` 浅暖色细边（E8DCC8，即参考卡片的
  边色），圆角 12→14；条内非图文件 chip 同步换浅边
- 发送中回显气泡：去掉 1.4px 黑描边（保留深色底与圆角）
- 聊天里的图片：全新渲染路径**无边框无底色**，只留 12px 圆角
- 聊天文字气泡的黑边保留（用户未确认要动，只动图片相关）

### 3. 多图不拼网格，一张一张（微信/QQ 式）
- 删掉整个马赛克网格编排（2 图并排/3 图一大二小/≥4 两列分行全部移除）
- 每张图独立一块：宽随气泡（竖图按 300 逻辑高封顶收窄），
  按原始比例等比显示；纵向依次排开，间距 6
- 比例来源：字节到手后用 `instantiateImageCodec(targetWidth: 24)`
  解缩略算宽高比（EXIF 方向已被解码器处理），按 ref 全局缓存，
  重进聊天页不重复解码；比例解出前用 240×158 默认比例占位，无缝切换
- 上传中回显走同一编排：本地字节直显，逐张等比出现
- 画廊交互不变：点任意一张进画廊，左右滑动看整条消息的图
