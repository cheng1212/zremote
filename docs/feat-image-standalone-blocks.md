# 变更说明：图片完全独立成块（无气泡底），微信式最终形态

> 基线：`530c47e`（一张一张排 + 去黑边）
> 日期：2026-09-09　依据：用户微信截图——「一张一张的，每一张都不相关，
> 也不需要什么底了」

## 改动

- 图片彻底脱离气泡：此前多图仍装在深色用户气泡里（有「底」）；
  现在每张图是**独立块**——右对齐、无边框无底色、按原始比例显示，
  纵向一张一张排，图与图 8px 间距，互不相关（微信发多张图的观感）
- 纯图片消息（无文字）不再出现任何气泡，只有图
- 图文混排：图片块在上，文字装回深色气泡在下；文件 chip 仍进气泡
  （chip 是浅色描边，裸放在米色背景上会看不清）
- 发送中回显同步同款编排：上传中图片独立块直显，状态行仍在气泡里
- 画廊交互不变：点任意一张左右滑看整条消息
