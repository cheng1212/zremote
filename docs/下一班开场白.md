## 五、可以顺手贴给它的环境事实（省得它再踩一遍）

```
- flutter test 必须绕过代理，否则全线报 WebSocketException：
  no_proxy='localhost,127.0.0.1,::1' NO_PROXY='localhost,127.0.0.1,::1' flutter test
  （flutter analyze 不受影响）
- 构建别用 build-flutter-apk.ps1（跑不起来），直接 flutter build apk --release
- 探针脚本需要环境变量 ZREMOTE_PROBE_LINK=<配对链接>，没有时自动 skip。
  探针会真的操作你桌面端，跑之前想清楚。
- 遍历 workspace 的探针会超时，default 项目有 99 个会话，要设短超时 + 命中即停。
```
