# ZCode Remote v4 协议接口参考（AI Agent 用）

> 来源：真实配对链接直连桌面端探针实测 + 桌面端运行时反编译考古（zcode.cjs / app.asar）。
> 桌面端版本：ZCode 3.10.1（Windows）。所有"实测"字段均经真机验证。
> 配对链接形状：`https://zcode.z.ai/remote/v4?sid=<device_sid>&hash=<hash>&t=<timestamp>&mid=<machine_id>&name=<device_name>&app_version=<version>`
> `sid` 是设备 ID，`hash` 是 HMAC 密钥（URL 编码的 base64），`mid` 是机器 ID，`t` 是过期时间戳。

---

## 连接握手（Relay 层）

```
WSS 地址：wss://zcode.z.ai/ws?mid=<mid>
流程（全 JSON 文本帧）：
C→S  {type:"auth_init", role:"terminal", device_sid:<sid>, meta:{platform,version,name}, client_ts}
S→C  {type:"auth_challenge", nonce:<随机串>}
C→S  {type:"auth_response", device_sid:<sid>,
       proof: base64url_nopad(HMAC-SHA256(key=utf8(hash), msg="<nonce>|terminal|<sid>"))}
S→C  {type:"auth_ack", pair_status:"matched"|"waiting"}
心跳：C→S {type:"pair_status_query", device_sid} 每 10s；S→C {type:"pair_status_ack", pair_status}
数据帧：{type:"data", payload:{...}}  ← 所有业务走 payload
关闭码：4004 not-found / 4009 session-conflict（同 mid 互踢）/ 4010 desktop-disconnected /
        4011 session-expired / 4012 workspace-closed / 4013 invalid-mobile-connection
```

## 信令层（Relay 数据帧里的 payload，`zcode_type` 字段区分）

| zcode_type | 方向 | 说明 |
|---|---|---|
| `bootstrap-request` / `bootstrap-response` | C→S / S→C | 整机概览：`result.workspaces[]`（桌面端已打开的工作区列表）、`result.tasks[]` |
| `workspace-list-request` / `response` | C→S / S→C | 工作区列表 + `activeWorkspaceKey` |
| `workspace-bridge-open` / `bridge-ready` / `bridge-error` | C→S / S→C | `{bridgeSessionId, bridgeGeneration, workspaceKey, taskId?, recoveryId?}` → ready 带 `{bridge:{bridgeSessionId, workspacePath, workspaceIdentity?, initialTaskId}}` |
| `workspace-reconnect-request` / `response` | C→S / S→C | 断线快速恢复 `{workspaceKey}` |
| `mobile-view-state-update` | C→S | `{viewState:{activeWorkspaceKey, activeTaskId?, updatedAt}, deviceInfo}` |
| `workspace-list-updated` | S→C 推送 | 工作区列表变化 |
| `bridge-degraded` | S→C 推送 | `{bridgeSessionId, reason}` |

## rpc-frame 分片（大消息）

`{zcode_type:"rpc-frame", bridgeSessionId, seq, messageSeq, fragmentIndex, fragmentCount, messageBytes, checksum:{crc32}, dataBase64}` — 每片 ≤512KB，消息 ≤16MB，≤64 片；收齐回 `rpc-frame-ack`。

## Channel IPC（rpc-frame 重组后即 IPC body）

请求头 `[reqType, reqId, channelName, methodName]` + arg 值；值编码 tag：0=Undefined 1=String 2=Buffer 3=VSBuffer 4=Array 5=Object(JSON) 6=Int(varint)。
reqType：100 Promise / 101 PromiseCancel / 102 EventListen / 103 EventDispose；resType：200 Initialize / 201 Success / 202 Error / 203 ErrorObj / 204 EventFire。

## L5 业务通道与方法

### `zcode-agent` — 会话/对话核心（V4，protocolVersion=3）

**命令** `sendConversationCommandV4({scope, envelope})`，envelope=`{commandId, clientId, sessionId, type, payload, issuedAt, baseRevision?(CAS), baseLogEpoch?(行级)}`：

| 命令 | payload | CAS |
|---|---|---|
| `createSession` | `{workspaceId, firstInput?:{text,attachments?}, config?, runtimeModel?}` | |
| `sendText` | `{text, attachments?, heldQueueDisposition?, toolDisallowlist?}` | |
| `stop` / `compact` / `pauseGoal` / `resumeGoal` | `{}` | pause/resume ✓ |
| `switchModelConfig` | `{provider, model, thought}` + 可选 `runtimeModel` | ✓；同配置→`{status:"noop", reasonCode:"config.unchanged"}`；provider 不在工作区注册表→`provider.notInRegistry` 错 |
| `switchCollaborationMode` | `{mode: build/edit/plan/yolo}` | ✓ |
| `setFollowupMode` | `{mode: queue/guide}` | ✓ |
| `setApprovalMode` | `{mode: askBeforeChange/autoEdit/planMode/fullAccess}` | ✓ |
| `resolveInteraction` | `{interactionId, answer:{optionId?\|action?\|freeText?\|content?}}` | |
| `retryTurn` / `forkAssistant` / `editUserQuery` / `applyFileRewind` | `{target:{rowId, entityId?}, newText?}` | ✓+行级 |
| `setAssistantFeedback` | `{target, feedback: like/dislike/null}` | ✓+行级 |
| `sendQueuedNow` / `deleteQueueItem` / `setAutoDrain` | `{queueItemId…}` / `{autoDrain}` | ✓ |
| `renameSession` / `deleteSession` | `{title}` / `{}` | |
| `cancelBackgroundWork` | `{workId}` | |

**查询**（channel 调用，非命令）：
- `conversationRowsRangeV4({sessionId, beforeRowId?, limit})` → `{rows[], atSeq, atLogEpoch, hasMore}`
- `conversationPlansV4({sessionId})` → `{plans[], atSeq, atLogEpoch}`
- `conversationFileChangesV4({sessionId, target:{rowId, entityId}, baseRevision, baseLogEpoch})` → `{files, additions, deletions, items:[{path, additions, deletions, writeCount, toolNames[], patches[]}]}`（3.10.1 起必须 target+CAS，缺则 zod 报错）
- `conversationFileRewindPreviewV4` 同上参数

**订阅**（EventListen）：
- `subscribeConversationV4({sessionId})` → 流式 delta 帧：snapshot + deltas（row.appended/upserted/removed、row.delta、state.updated、modelTransition）
- `subscribeSessionsIndexV4({runtimePolicy})` → 会话索引
- `subscribeWorkspaceConfigV4` → 工作区配置

**快照 snapshot 关键字段**：`control.{phase, canStop, stopState, activeWorks[]}`、`config.{provider, model, thought, thoughtLevels[], mode, approvalMode, followupMode}`、`revision`、`usage.{contextWindow.{usedTokens, maxTokens, autoCompactThresholdTokens, cache{latestHitRate, hitRate, hitRateRequestCount,…}, breakdown[]}, cumulative.{inputTokens, outputTokens, cacheReadTokens, cacheWriteTokens}}`、`queue.{items[], autoDrain}`、`plan.{items[{id, content, status}], updatedAt}`、`goal`、`pendingInteractions[]`、`pendingCommands[]`、`backgroundWorks[]`、`subagents.{revision, childSessionIds[], running[], endedTotal}`、`rows.{window[], totalCount, firstRowId}`

**activeWorks[] 项**：`{kind: primaryTurn|foregroundSubagent|compact|goalVerifier|goalContinuation|turnSteer, foregroundExecutionId?, startedAt}`

**backgroundWorks[] 项**：`{workId, kind: bash|subagent, title, status: running|resultPending|failed|cancelled, startedAt, endedAt?, cancellable?, blocked?, anchorRowId?, childSessionId?}`

**subagents 字段**：`{revision, childSessionIds[], running:[{childSessionId, agentId?, toolCallId?, subagentType, title, summary?, status: running|waiting|blocked, startedAt}], endedTotal}`

**行类型**：`userInput` / `assistantText` / `reasoning` / `toolCall` / `subagent` / `turnHeader` / `timelineMarker`；行内 `state: streaming|…`；turnHeader 带 `{rowId, turnId, entityId, state, startedAt, endedAt, activeMs, fileChanges?}`

### `zcode-task` — 任务管理

- `prepareWorkspace(scope)` → `{configOptions:[{id: model|thought_level|mode, options:[{value,name,modelProviderName?}], currentValue}], slashCommands[]}`
- `listTasks(scope)` / `listPinnedTasks(scope)` / `listArchivedTasks(scope)` → 任务对象数组
- 任务对象字段（实测）：`{taskId, traceId, title, titleOverridden, workspacePath, createdAt, updatedAt, mode, model:"<providerId>/<modelId>", thoughtLevel, provider, status, pinned?, lastError?}`
- `archiveTask(scope+taskId)` / `unarchiveTask` / `deleteTask` / `renameTask({title})` / `setTaskPinned({pinned})` / `setTaskUnread`
- `getTaskTokenUsage(scope)` → 累计 token
- `getTaskSnapshotWithEtag(...)`

### `usage-stats` — 用量统计

- `getAppUsageSnapshot([{range: all|7d|30d, timeZone?: "GMT+08:00"}])` → `{range, generatedAt, timeZone, summary:{…}, models[], dailyModelUsage[], heatmap[], tools[]}`
- summary 字段：`{totalTokens, inputTokens, outputTokens, reasoningTokens, cacheCreationTokens, cacheReadTokens, cacheHitRate, totalSessions, totalTurns, toolCallCount, toolErrorRate, modelErrorRate, avgTimeToFirstTokenMs, avgTurnDurationMs, activeDays, currentStreakDays, peakDayTokens, favoriteModel{modelId}}`
- models[] 项：`{modelId, totalTokens, inputTokens, outputTokens, requestCount, share}`
- dailyModelUsage[] 项：`{date: "yyyy-MM-dd", models:[{modelId, totalTokens}]}`
- 说明：**整机级**（无 scope），非单会话；`range` 必填；`timeZone` 可选、接受 GMT 偏移串；bigmodel 额度查询走同通道其他方法（需 bigmodel key）

### `workspace/*` — 工作区配置（在同一 channel 的路由表里，未完全逆向）

- `workspace/readState` → `{modelCurrent, modelCount, providerCount, preferWorkspaceDefaults, …}`
- `workspace/updateProviderRegistry` / `upsertModelProvider` / `removeModelProvider`
- `workspace/setDefaultModel` / `setDefaultThoughtLevel` / `setDefaultMode` ← **移动端未接，可做"新会话默认模型"的正解**
- `workspace/generateText` / `cancelGenerateText`
- `workspace/hooks/trustGrant` 等

### `model-provider` — 供应商凭据管理

`getAll` / `getAllCached` / `save` / `delete`（移动端未接）

### `skills` — 技能列表

`list({workspacePath, workspaceIdentity?, provider:"glm"})` → 技能列表（composer `$name` 触发）

### `commands` — 斜杠命令

`list(scope)` → 命令列表

## 关键行为事实（实测）

1. **模型配置是会话级共享状态**，双向"后写者赢"——任何端写入都推 `state.updated` 给对方。
2. **桌面端有"同步当前模型"机制**（日志 `完成同步当前模型 runtime config 到 ZCode agent`，高频 10-35s/次），会把桌面当前模型推给活跃会话运行时——与手机端选择冲突时形成拉锯。
3. **`config.unchanged`** 返回 `{status:"noop"}` 非错误；**noop 不产生新 revision**，CAS 地板只应在 `accepted` 时 +1。
4. **注册表回退**：provider registry 更新后会话模型若不在健康列表，桌面自动切到 `listModels()[0]` 并广播（`registryFallback`）。
5. **thoughtLevels 随模型家族**（GLM low/high/max、NVIDIA low/medium/high、qwen enabled/disabled）；非法 thought 服务端静默忽略。
6. **CAS stale 自愈**：`baseRevision` 过期 → `{status:"stale", revisionAtDecision}` → 客户端用该 revision 重试一次即成功。
7. **模式词表**：build/edit/plan/yolo；**审批词表**（setApprovalMode）：askBeforeChange/autoEdit/planMode/fullAccess——两套独立。
8. **subagents.running[].status**：running / waiting / blocked；**backgroundWorks[].status**：running / resultPending / failed / cancelled。
9. **工作区=电脑实际文件夹**，会话按工作区隔离；协议无 project_id/标签概念。
10. **20 个自动化上限**（`automation limit reached`）；`runAutomationNow` 对同一自动化重复触发返回 `{status:"duplicate"}`。
